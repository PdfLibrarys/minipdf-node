# MiniPdf for Node.js

[Full guide (English)](../README.md)

## Quick start

```bash
npm install minipdf
```

```javascript
const minipdf = require('minipdf')

minipdf.convertToPdf('report.docx', 'report.pdf')
```

使用方法については [Node.js ガイド](../README.md) をご覧ください。
