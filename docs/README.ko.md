# MiniPdf for Node.js

[Full guide (English)](../README.md)

## Quick start

```bash
npm install minipdf
```

```javascript
const minipdf = require('minipdf')

minipdf.convertToPdf('report.docx', 'report.pdf')
```

사용 방법은 [Node.js 가이드](../README.md)를 참조하세요.
